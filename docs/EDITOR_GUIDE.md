# NDSES Editor Guide

This guide is for NDSES staff managing website content in WordPress.

## Edit Page Content

Open the page in WordPress, update the Hero fields or Page Sections, preview the page, and publish when ready. Page headings, copy, images, buttons, FAQs, downloads, and calls to action should be edited in WordPress.

## Replace Images

Use the image field inside the relevant Hero or Page Section. Add descriptive alt text before publishing.

## Add or Reorder Sections

Use the Page Sections flexible content field. Add approved layouts, drag to reorder, and avoid duplicating sections with the same message.

## Update Contact Information

Open NDSES Site Settings and update phone number, email, address, hours, service area, and footer details.

## Update Collection Information

Open the relevant Community entry. Update service day, trash schedule, recycling schedule, holiday rules, bulk-item policy, downloads, and FAQs.

## Create a Weather, Closure, or Delay Notice

Create a Service Notice. Set Notice Enabled to true, choose the notice type, write the public title and summary, set priority, choose timing, select affected communities or services, and choose display locations.

## Choose Banner, Popup, or Page Display

Use Display Locations. Choose Site-wide announcement bar for the top banner, Modal popup for urgent dialogs, and page/community locations for targeted notices.

## Schedule a Notice

Set Display Start and Display End. Use Show Until Manually Resolved when the end time is unknown.

## End or Resolve a Notice

Change Notice Status to Resolved or Expired, or turn Notice Enabled off. Publish the update.

## Publish a Service-Restoration Notice

Create a new Service Notice with type Service Restored, set the affected communities and services, and publish it to the relevant pages.

## Preview Changes

Use the WordPress preview link. Draft preview requires the configured preview secret.

## Publish Changes

Publish or update the WordPress entry. The webhook should refresh the relevant Next.js pages automatically.
